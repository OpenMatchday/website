Open Matchday

Privacy

Stub for product privacy expectations. Local match production does not require an Open Matchday account or Internet access.

Local production

  • Event state, recordings, and social drafts stay on devices you control unless you export or publish them.
  • Director approval gates which devices join a session.
  • Optional online features (registry contribution wizard, social publishing) are separate from local production.

Public registry

  • The teams repository is a public Git registry of sports, competitions, clubs, teams, seasons, and players.
  • Only public fields are allowed. Private contacts, dates of birth, and similar sensitive fields are banned from the schema.
  • Minors default to no photo. Consent evidence for photos is never committed to Git.

Online accounts (optional)

  • Contribution and publishing flows use separate credential planes from local production accounts.
  • Social publishing uses official provider APIs only after explicit operator approval; unverified providers stay disabled.
  • This static site does not embed community backend secrets.

Contact for privacy and takedown

Open a GitHub issue in OpenMatchday/teams with title prefix takedown: and identify the stable ids or file paths. Do not send unnecessary personal data. See the takedown page for process limits.

No dedicated public email is published yet. The GitHub issue path is the contact method for this stub. Maintainers will not promise total erasure of Git history.
