Takedown

Request removal or replacement of public registry content. This page is a public stub aligned with the docs process.

Scope

Covers public registry content in the teams repository (clubs, teams, players, photos, and related metadata) and mirrored website catalog copies after generation tasks land.

How to request a takedown

  1. Open a GitHub issue in OpenMatchday/teams with title prefix takedown: and identify the stable ids or file paths.
  2. Include enough detail to locate the content (stable id, package id, photo path). Do not send unnecessary personal data.

Full process text: docs/privacy/takedown.md.

Git history

Open Matchday does not promise total erasure of Git history. Removing a file from main stops shipping it in new clones and releases, but historical commits, forks, and caches may still contain prior copies. Maintainers will not rewrite public history for routine takedowns.

Priority. For rights or objection cases, maintainers prioritize stopping distribution on current main and future releases.
