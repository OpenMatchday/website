Matchday workflow

One composition from install to export. Control stays on the local LAN; media uses Wi-Fi or Ethernet only.

  1. Install or build the local app packages for the platforms you run (Flutter app plus media modules per the capability matrix).
  2. Create or open an event. Optionally pin offline registry snapshots for teams and seasons.
  3. Pair devices: BLE or QR/manual IP for control. Director approves each device and assigns roles before it joins the session.
  4. When OCR is used, calibrate the scoreboard reader with four corners and define regions.
  5. Operators set clocks, scores, lineups, graphics and themes. Social drafts stay local until publishing accounts are connected.
  6. Director selects Preview and Program, cuts to air, and enables recording and live outputs with independent layouts.
  7. After the match: stop outputs, export recordings and social drafts. Optionally contribute roster updates online through the website path.

Control versus media

  • Control-plane pairing may use BLE where the matrix allows, or QR/manual IP on every supported platform.
  • Media streams use Wi-Fi or Ethernet only. The product UI states this and refuses cellular or BLE for media.
  • No paired device joins the event session until the director explicitly approves it.
